EVERPAGES STATIC SHOWCASE WEBSITE

Files:
- index.html: website content and category/subcategory galleries
- styles.css: chocolate-brown and cream styling, responsive layout
- script.js: mobile navigation and footer year

CATEGORY EXPERIENCE:
Click Story Books, Personal Books, or Knowledge Books in the main
collection cards or navigation to jump to a visual gallery of their
subcategories. Each subcategory has a sample photo, description, and
an enquiry link. On desktop, the navigation subcategories appear in
dropdown menus. On mobile, the subcategory links expand below each
category.

HOW TO CUSTOMISE:
1. Open index.html in a browser to preview.
2. Replace the demo WhatsApp number in index.html:
   https://wa.me/910000000000
   Use country code + number only, without +, spaces or hyphens.
3. Replace sample photos with your actual book cover photos when ready.
4. Update titles and descriptions inside the matching type-card sections.
5. Add new subcategory cards by duplicating an existing article with class
   type-card and assigning a unique id.
6. Email is already set to everpagesin@gmail.com.

This is a static showcase site. It does not yet process online payments
or manage orders. Enquiry links open the contact section.
